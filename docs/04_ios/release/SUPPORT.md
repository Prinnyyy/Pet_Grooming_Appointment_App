# Groomly Support

Last updated: July 9, 2026

Use this page for Groomly app support requests, general feedback, feature requests, privacy questions, and account deletion questions.

## Support Requests

Open a support issue in the public project tracker:

https://github.com/Prinnyyy/Pet_Grooming_Appointment_App/issues

Include the app screen, the action you were taking, the device or simulator model, and any safe support reference shown in the app. Do not include passwords, verification links, payment information, private access tokens, or full screenshots that expose another user's personal information.

## General Feedback

Use the same issue tracker for general feedback about customer requests, groomer offers, bookings, chat, image display, account profile settings, or notification behavior.

## Feature Requests

Use the issue tracker for feature requests. Helpful requests describe the user role, the workflow, the expected result, and why the current behavior does not cover the need.

## Privacy and Account Deletion

The app includes an Account screen delete-account action. For privacy questions or deletion questions, open a support issue and include only safe account context, such as your user role and the short support reference shown in the app.
