# Evaluation Rubric

| Criterion | Weight | Evidence |
| --- | ---: | --- |
| Business correctness | 25% | fields, states, operations, navigation, Mobile/Studio, no invented buffer/action |
| Scanning efficiency | 20% | time/pet/status anchors and chronological continuity |
| Brand consistency | 15% | Beckon warmth, mint identity, shared Customer/Groomer language |
| Accessibility | 15% | XL reflow, 44pt targets, wrapping, VoiceOver order, contrast/motion rules |
| Information density | 10% | useful daily context without dashboard clutter |
| SwiftUI feasibility | 10% | maps cleanly to `NavigationStack`, `TabView`, `ScrollView`, semantic text, adaptive layouts |
| Visual completion | 5% | coherent spacing, hierarchy, states, and polish |

Score each category from 1–5, multiply by its weight, and record evidence. A concept is not approvable below 80/100.

## Automatic rejection

- Invents a core business capability or state.
- Covers, clips, or truncates primary business text.
- Makes Cancel/Delete persistently prominent in the agenda.
- Depends on web-only interactions such as hover, desktop drag/drop, or right click.
- Breaks from Beckon's approved brand language.
- Accessibility XL cannot complete date selection, appointment inspection, detail navigation, messaging, or eligible completion.
