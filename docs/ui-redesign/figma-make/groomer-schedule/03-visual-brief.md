# Visual Brief — Beckon Warm Utility System

The screen must feel like Beckon: a warm pet-care product adapted for focused groomer operations, not an enterprise dashboard or generic SaaS template.

- Warm off-white page background.
- Muted mint/teal as the primary brand and action color.
- White, stable content surfaces with soft borders and restrained shadows.
- One shared radius scale; generous enough to retain Beckon's softness without turning every row into a floating card.
- Pet-care warmth through pet imagery or paw/avatar treatment, friendly copy, and measured brand accents.
- Groomer density is higher than Customer density: smaller headers, tighter rows, fewer decorations, stronger time/status alignment.
- Preserve the Customer Home and Pet Selection references as the brand family; do not copy their hero density into Schedule.
- Status uses a small badge, icon, or timeline marker. Never tint an entire appointment card with saturated state color.
- Cards represent complete business objects. Summary metrics and every form-like line should not each become a separate card.
- Use SF Pro semantic typography and SF Symbols semantics. Avoid cartoon typography and web-dashboard icon sets.
- Navigation and bottom tabs should read as native iOS structures even when Beckon styling is layered on top.

Use the approved Figma system rather than sampling arbitrary colors or dimensions from screenshots. Relevant formal components include Status Badge `32:148`, Pet Avatar `32:191`, Section Header `32:236`, Appointment Card `32:642`, and feedback states `32:693`, `32:744`, `32:783`.
