# Concept Requirements

Generate three distinct page-level concepts using the exact fixtures in `05-content-fixtures.md`.

## 1. Balanced Operations

Balanced summary, date navigation, chronological appointment objects, and restrained inline actions. This is the closest evolution of the approved normalized calibration.

## 2. Agenda First

Time is the dominant continuous scan rail. Appointment content aligns to time without becoming a desktop calendar grid. Preserve native iPhone scrolling and Beckon surfaces.

## 3. Compact Schedule

Highest useful Groomer density while preserving 44pt targets, readable status, pet/service priority, and content-driven height. It must still feel related to the Customer product.

## Required output for every concept

- One 393pt-wide Default frame and one Accessibility XL frame using identical content.
- Native top navigation title and five-item bottom tab structure with Schedule selected.
- Date switching affordance, selected-day summary, three chronological appointments, loading, empty, and persistent error samples or clearly linked state panels.
- Appointment cards/rows open Booking Detail.
- Message is real. Complete is shown only for confirmed bookings. No Check In or Start Service.
- Cancel is not a persistent full-width list action; note that it belongs in detail and the future design requires confirmation.
- Correct Mobile/Studio text.
- Travel Buffer is labelled `Not implemented` outside the product UI; do not invent it as schedule data.
- Content clears the bottom safe area and tab bar.
- XL demonstrates actual reflow: growing cards, stacked content/actions, moved badges, and no primary truncation.
- Use existing Beckon references and formal design-system semantics. Do not introduce a second Customer/Groomer design system.
