# Tasks And Evidence

[Current State](../00_memory/CURRENT_STATE.md) owns task allocation and unfinished work. [Roadmap](ROADMAP.md) holds unadopted/deferred product directions; it does not start tasks.

Use [task plans](../superpowers/README.md) for complex adopted objectives only. Small changes need no separate task report. Preserve completed evidence at stable paths and use [SQL review index](sql_reviews/README.md) for the named backend acceptance record.

[Screenshot template](SCREENSHOT_UI_REWORK_TASK_TEMPLATE.md) remains an optional task-specific aid for mapping screenshots to existing ownership. New behavior still needs the decision and authorization required by [Development Guide](../05_workflow/DEVELOPMENT_GUIDE.md).

Task Ledger, the former execution queue and meta-review template are historical/redirect entries. They no longer allocate numbers, duplicate progress, require periodic work or trigger automatic archival.
