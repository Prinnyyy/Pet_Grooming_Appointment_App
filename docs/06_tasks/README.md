# Task Directory

Active contents:

- `TASK_LEDGER.md` - task numbering, active/recent status, and next ID.
- `TASK_INTAKE_TEMPLATE.md` - optional task intake.
- `HANDOFF_TEMPLATE.md` - handoff/checkpoint format.
- `REVIEW_TEMPLATE.md` - review format.
- `LIGHTWEIGHT_TASK_PROMPT_TEMPLATE.md` - quick task prompt helper.
- `SCREENSHOT_UI_REWORK_TASK_TEMPLATE.md` - future Groomly screenshot rework template.

Historical task files T-001 through T-048 and workflow task records live under `docs/09_frozen/task_records_2026-07-06/`.

Do not create a standalone task file by default for tiny docs or status work. Create one when the user asks, when a Standard/Deep task needs its own spec, or when a long task needs durable checkpoints.
